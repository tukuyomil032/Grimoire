# 10 — Internationalization (i18n)

## Overview

Grimoire supports multiple languages using `i18next` + `react-i18next`. English is the default language; Japanese is the first additional language.

## Configuration

```typescript
// src/lib/i18n.ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import enCommon from '@/locales/en/common.json';
import enEditor from '@/locales/en/editor.json';
import enMechanics from '@/locales/en/mechanics.json';
import jaCommon from '@/locales/ja/common.json';
import jaEditor from '@/locales/ja/editor.json';
import jaMechanics from '@/locales/ja/mechanics.json';

i18n.use(initReactI18next).init({
  resources: {
    en: { common: enCommon, editor: enEditor, mechanics: enMechanics },
    ja: { common: jaCommon, editor: jaEditor, mechanics: jaMechanics },
  },
  lng: 'en',
  fallbackLng: 'en',
  ns: ['common', 'editor', 'mechanics'],
  defaultNS: 'common',
  interpolation: { escapeValue: false },
});
```

## Translation File Structure

```
src/locales/
  en/
    common.json      # General UI: menus, buttons, labels
    editor.json      # Editor-specific: panel titles, actions
    mechanics.json   # MythicMobs mechanic descriptions
  ja/
    common.json
    editor.json
    mechanics.json
```

## Translation Scope

| Category | Translated? | Example |
|----------|------------|---------|
| UI labels | Yes | "File", "Edit", "Export" |
| Menu items | Yes | "New Project", "Open File" |
| Panel titles | Yes | "YAML Preview", "Properties" |
| Tooltips | Yes | "Click to add a new mechanic block" |
| Error messages | Yes | "Required field is empty" |
| Mechanic names | **No** | `damage`, `projectile` stay English |
| Mechanic descriptions | Yes | "Deals damage to the target" → "ターゲットにダメージを与える" |
| Parameter names | **No** | `amount`, `velocity` stay English |
| Parameter descriptions | Yes | Localized help text |
| Keyboard shortcuts | **No** | `Ctrl+S`, `Cmd+Z` are universal |

## Language Switching

- Topbar has a language toggle (globe icon from Lucide)
- Switching calls `i18n.changeLanguage('ja')`
- Preference saved to `@tauri-apps/plugin-store`
- App re-renders immediately (React context-based)

## Adding New Languages

1. Create `src/locales/{code}/` with `common.json`, `editor.json`, `mechanics.json`
2. Import in `src/lib/i18n.ts`
3. Add to language selector dropdown
4. MythicMobs schema descriptions include a `{ en: string; ja: string }` object — extend to `{ en: string; ja: string; [key: string]: string }`
